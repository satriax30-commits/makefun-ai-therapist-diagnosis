Entry for the make.fun bounty **Your AI Therapist's Diagnosis**: a tiny
deterministic Node 22 program (`main.ts`, stdlib only, no network, no
wall-clock, no randomness) that writes one funny single-line diagnosis from
an AI therapist to `/output/entry.txt`, with a 1–200 character gate
validation and a read-back self-check.

The diagnosis: acute notification anxiety — the patient checked their phone
214 times today, 38 of them during dinner with Maya. The phone is fine.
The patient is the notification.

## Run it

```sh
node main.ts [output-dir]
```

With no argument it writes to `/output/entry.txt`.
